## Qué es Everforged Software

Everforged Software es un desarrollador independiente (no una agencia ni una
fábrica de plantillas) que diseña y construye software y páginas web a
medida para negocios que necesitan una solución que calce con su operación
real, sin plantillas genéricas ni funcionalidades de más.

## Servicios

1. **Sistemas a medida**: herramientas para gestionar el día a día de un
   negocio — pedidos, inventario, clientes, procesos internos. Se construyen
   alrededor de cómo trabaja el cliente, no de un molde genérico.
2. **Sitios y páginas web**: sitios corporativos, landing pages y tiendas
   online rápidas y fáciles de usar, pensadas para que quien visite entienda
   el servicio y contacte al negocio.
3. **Automatización de procesos**: conectar sistemas entre sí y con
   herramientas como WhatsApp, correo o planillas, para que tareas
   repetitivas dejen de hacerse a mano. Ejemplos concretos:
   - Gestión de múltiples procesos/flujos de trabajo que dependen entre sí.
   - Correos programados (recordatorios, reportes, avisos automáticos).
   - Mensajes automáticos por WhatsApp ante ciertas acciones.
   - Procesos particulares y repetitivos propios de cada negocio.
4. **Inteligencia artificial aplicada**: para negocios que se benefician de
   responder consultas automáticamente, clasificar información o generar
   contenido. Se evalúa junto al cliente qué tan grande es la necesidad y el
   costo real de resolverla — no se ofrece IA "porque sí".

## Forma de trabajo y pago

No hay tarifas fijas de catálogo. Cada proyecto parte con un análisis de lo
que realmente se necesita, y desde ahí se define un plan de trabajo y de
pago a medida.

- **Aplicaciones y sistemas a medida**: el costo se ajusta según la etapa.
  - Mientras se construye: el pago cubre en conjunto el desarrollo
    personalizado, la infraestructura en la nube y la mantención, durante el
    tiempo definido en el plan de trabajo.
  - Cuando el sistema está terminado y estable: el costo baja — se mantiene
    solo el pago de infraestructura y respaldos, sin el desarrollo activo.
- **Páginas web**: modelo más simple. Se parte con un plan estándar que
  incluye hosting y mantención; las modificaciones y ajustes van incluidos
  en el plan, no se cobran aparte.

No se entregan cifras exactas de precio por chat: siempre se invita a
conversar el proyecto por WhatsApp o correo para armar una propuesta real.

## Proceso de trabajo

1. **Descubrimiento**: conversación sobre el negocio, el problema a resolver
   y el resultado esperado.
2. **Propuesta**: alcance, tecnología y tiempos en una propuesta clara.
3. **Desarrollo**: iteraciones cortas, con avances visibles y espacio para
   ajustar el rumbo.
4. **Entrega y soporte**: lanzamiento acompañado y disponibilidad para
   evolucionar el producto después.

## Sobre el fundador

Everforged Software lo lleva un solo desarrollador (no una fábrica de
plantillas). Trabaja directamente con cada cliente si tiene una idea clara
de lo que necesita, evaluando en conjunto cómo construirla de forma
realista, con plazos y alcance definidos desde el principio. Entre lo que ha
construido: sistemas de gestión en uso real dentro de negocios activos,
automatización de tareas que hoy se hacen a mano o por WhatsApp, y
plataformas pensadas para soportar el crecimiento del negocio, no solo el
lanzamiento.
